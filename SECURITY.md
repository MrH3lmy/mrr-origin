# Security policy

MRROrigin is pre-release software and does not yet publish supported security versions.

Please do not report suspected vulnerabilities in a public GitHub issue. Contact the repository owner privately through their GitHub profile until a dedicated security-reporting address is published.

Do not include Stripe credentials, webhook secrets, access tokens, customer personal data, or exploitable proof-of-concept details in public discussions.
