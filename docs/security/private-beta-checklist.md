## How to use this checklist

- Every open item should have a linked GitHub issue before private beta starts; items 2, 6, and 7
  are already flagged as open decisions on #27 pending owner input, per `AGENTS.md`'s "record the
  ambiguity on the issue instead of inventing product behavior."
- "Done" items are not one-time: re-verify item 1 (cross-tenant isolation) on every PR that adds a
  new repository or endpoint family, per `ARCHITECTURE.md`'s tenancy rules — that requirement does
  not expire when this checklist is checked off once.
